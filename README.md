# Pico OS
Small RTOS for Raspberry Pico & Pico 2, using Rust

## Goals
- Multitasking
- Basic shell
- Display (2.4" TFT)
- Audio (Speaker-based)
- Gaming!

## Roadmap
- ✅ LED Blink
- ✅ Clock / Timer 
- 🛠️ UART Output
- ❌ Heap allocation
